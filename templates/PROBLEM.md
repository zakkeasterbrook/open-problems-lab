# Problem intake

Anyone can use this template for any meaningful problem. Start with the question and desired outcome; fill in technical details as the investigation develops. Keep confidential ideas outside the public repository until cleared for disclosure.

- **Verification method and stop/failure criteria:**
- **Commercial or confidentiality review:** public / private / review required
- **Current status:** proposed

## Investigation log

Record dated attempts, code, data, measurements, uncertainties, negative results and changes in assumptions. Cite original work. Never label a proposal as solved before it meets its success criteria.

## Outcome

Explain what actually works, what failed, limitations, remaining tests, applicable disclosure restrictions, and recommended next steps. Link reproducible artifacts and identify any AI assistance. Record whether the result is an idea, test, prototype, written proof, independently reviewed work, or validated deployment.
